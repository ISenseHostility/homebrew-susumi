# Susumi for Homebrew

The Homebrew tap of `susumi`, the command-line tool of [Susumi](https://susumi.dev): list, create, move and comment
on work items from the terminal.

```
brew install isensehostility/susumi/susumi
```

`brew upgrade susumi` gets a newer one. The formula is in `Formula/`, and each release here has the archives for
macOS, Linux and Windows with their checksums. Both are written by the release of the CLI, not by hand.

How to use it: [susumi.dev/docs#cli](https://susumi.dev/docs#cli).
